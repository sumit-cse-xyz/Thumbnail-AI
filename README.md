# AI Thumbnail Generator

An AI-powered web application that helps users create attractive YouTube thumbnails using simple text prompts.

The main idea behind this project was to explore how AI tools and workflow automation can be combined to build a functional web application without traditional frontend coding.

## About the Project

I built this project using two main platforms:

- **Frontend – YouWare AI:** The complete frontend was generated using AI. I created the user interface without writing a single line of frontend code manually.
- **Backend – n8n:** Used n8n to build the backend automation workflow, manage API requests, and connect the frontend with AI image generation services.
- **Integration – Webhooks:** Used webhooks to establish communication between the frontend and backend.

## Features

- Generate YouTube thumbnails using text prompts.
- AI-powered image generation.
- Simple and user-friendly interface.
- Automated backend workflow using n8n.
- Frontend and backend communication through webhooks.

## How It Works

1. The user enters a prompt in the web application.
2. The frontend sends the prompt to the n8n webhook.
3. n8n processes the request and connects with the AI image generation service.
4. The AI service generates an image based on the prompt.
5. The generated thumbnail is returned and displayed on the frontend.

## Tech Stack

| Technology | Usage |
